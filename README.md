# AI Gym Trainer

A real-time AI-powered gym coaching app built with Streamlit. It uses your webcam to detect body pose, count exercise reps, analyze form, and deliver voice coaching generated by an LLM — all running locally in your browser.

---

## Demo

> Launch the app, log in, pick an exercise, and start working out. The camera feed shows your skeleton overlay in real time, reps are counted automatically, and a voice coach gives you live feedback on your form.

---

## Features

- **Real-time pose detection** — MediaPipe's full-body 33-landmark model tracks your skeleton at 30 fps via WebRTC webcam streaming
- **Automatic rep counting** — joint-angle stage machine counts reps for 7 exercises without any button presses
- **Form analysis** — per-exercise metrics (depth, alignment, swing, torso lean, back arch, etc.) with pass/fail thresholds
- **AI voice coaching** — Groq (Llama 3.3 70B) generates short coaching cues; gTTS converts them to speech and plays them in-browser
- **Progress dashboard** — volume bar chart, weekly trend line, and exercise-mix donut chart backed by SQLite
- **User accounts** — registration and login with bcrypt-hashed passwords

## Installation

```bash
# 1. Clone
git clone https://github.com/Pratap-2/AI-Gym-Trainer.git
cd AI-Gym-Trainer

# 2. Create and activate a virtual environment
python -m venv .venv

# Windows
.\.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set your Groq API key
# Create a .env file in the project root:
echo GROQ_API_KEY="your_key_here" > .env
```

## Usage

1. **Create an account** or log in with existing credentials.
2. In the **sidebar**, select an exercise, set your target sets and reps, then click **START WORKOUT**.
3. Allow the browser access to your camera when prompted.
4. **Position yourself** so your full body is visible in the frame.
5. The app counts your reps, shows form metrics in real time, and plays voice cues.
6. Click **END WORKOUT** when done — the session is saved to the database.
7. Visit the **Progress** section to see your workout history charts.

## How It Works

### Pose Detection Pipeline

1. The browser streams webcam frames to a Python `VideoProcessorBase` via WebRTC.
2. Each frame is passed to MediaPipe's `PoseLandmarker`, which returns 33 body landmarks.
3. The active exercise's detector reads the relevant landmarks, computes joint angles using the law of cosines, and runs a stage machine (e.g. `up → down → up` = 1 rep).
4. Metrics (reps, form flags) are written to a thread-safe shared state and synced into Streamlit's `session_state` on each UI refresh.

### Voice Coaching Pipeline

1. Workout events (`workout_started`, `set_completed`, `bad_form_detected`, etc.) are emitted by the detectors.
2. A Groq LLM call generates a 10–15-word coaching cue tailored to the specific event and any active form issues.
3. The cue is converted to an MP3 with gTTS and played inline via Streamlit's audio component.
4. A 5-second cooldown prevents spamming for non-critical events.

## Adding a New Exercise

1. Create `detectors/my_exercise_detector.py` inheriting from `core.base_exercise.BaseExercise`.
2. Implement `process(landmarks) -> dict` (returns current metrics) and `reset()`.
3. Add the exercise name to the list in `services/config/workout_config.py`.
4. Map the exercise name to your detector class in the dispatcher in `services/vision/`.

---

## Known Limitations

- WebRTC camera access requires HTTPS in production deployments (works on `localhost` without it).
- Voice coaching requires an active internet connection (Groq API + Google TTS).
- Pose detection accuracy drops significantly in low light or when the full body is not in frame.
- The app is single-user per browser tab; multiple simultaneous users each get their own session.
